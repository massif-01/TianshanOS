## 发布条件

- Fork 分支和上游 PR 执行构建/回归，不发布正式版本。
- 上游 `RMinte-AI/TianshanOS` 的 main 合并推送，构建与 WebUI 回归均成功后，依据 version.txt 自动创建 v0.5.2。
- Release 绑定触发构建的 github.sha，中文正文来自 `docs/releases/v0.5.2.md`，不使用自动生成的英文提交摘要替代正文。
- tools/check_release.py 要求 tag、version.txt、构建版本一致，并检查中文说明。没有对应说明的新版本不能静默发布。
- 若同版本 Release 已存在，main 流程保持既有的跳过行为，不覆盖正式版本。发布新版本需同步更新版本与说明。
- 本轮仅提交和提 PR，不自行合并，也不提前创建 v0.5.2 标签或 Release。
